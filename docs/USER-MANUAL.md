# User Manual

## Start and sign in

Open the deployed HTTPS URL. Select **Get started**, enter a name, email, and password of at least 12 characters. Registration signs you in and creates standard income/expense categories. Returning users select **Sign in** and enter their email address—not their display name. If the password is forgotten, select **Forgot password?**, submit the account email, and use the emailed link within 30 minutes. Use **Sign out** on a shared device.

## Dashboard

The dashboard shows current-month income, expenses, balance, number of overspent budgets, six-month bars, expense categories, budget progress, and five recent transactions. Empty panels provide links to create the missing data.

## Transactions

1. Select **Transactions** or the mobile **Add** button.
2. Choose **+ Income** or **+ Expense**.
3. Enter a positive amount, date, matching category, description, and optional note.
4. Save. Success/error feedback appears above the list.
5. Use Search, Type, Category, Month, From, and To filters. A month takes precedence over date range. Select Clear all to reset.
6. Use Edit to change all fields or Delete and confirm to permanently remove one owned record.

## Budgets

Select a month, choose **Create budget**, pick an expense category, and enter its monthly limit. Each category can have only one budget per month. Cards display spent, planned, remaining/over amount, percentage, and an overspending warning. Edit or delete with the card actions.

## Analytics

Analytics compares six months of income and expenses, summarizes the current balance/savings rate, ranks current expense categories, and shows current budget health. All figures come from entered records.

## Settings and dark mode

Settings changes your name, unique email, display currency, and timezone. Password change requires the current password; on success, other sessions are revoked. The sun/moon button switches and remembers light/dark mode on that browser.

## Data and safety

ExpenseTrack does not connect to a bank. Do not enter card numbers, PINs, banking passwords, government IDs, or secrets in descriptions/notes. Use a unique password and sign out on untrusted devices. Contact the real deployment administrator for data deletion or suspected compromise.
